# cpp-learning-all

A consolidated repository combining 17 C and C++ learning repositories into a single monorepo, preserving complete commit history from each original project.

## Repository Overview

| Folder | Original Repository | Description |
| :--- | :--- | :--- |
| [`array-concept-c`](./array-concept-c) | `Kumar-LLP/array-concept-c-` | Array declarations, indexing, traversal, and manipulation in C++. |

| [`constructor-concept-c`](./constructor-concept-c) | `Kumar-LLP/constructor-concept-c-` | Class constructors, object initialization, and member functions in C++. |
| [`exception-handling-cpp`](./exception-handling-cpp) | `Kumar-LLP/Exception-Handling-cpp` | Exception handling mechanisms with `try`, `catch`, `throw`, and error management. |
| [`file-input-output-cpp`](./file-input-output-cpp) | `Kumar-LLP/file-input-output-cpp` | File handling using `fstream` (`ifstream`, `ofstream`) for reading and writing files. |
| [`inheretance-cpp`](./inheretance-cpp) | `Kumar-LLP/inheretance.cpp` | Single and multiple inheritance examples and class hierarchies in C++. |
| [`inheritance-concept-cpp`](./inheritance-concept-cpp) | `Kumar-LLP/inheritance--concept-.cpp` | Inheritance implementations demonstrated both standardly and using pointer concepts. |
| [`learning-c`](./learning-c) | `Kumar-LLP/learning-c-` | Day 1 C++ fundamentals, basic structure, and introductory exercises. |
